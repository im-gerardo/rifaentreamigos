# Instrucciones para agentes de programación

Antes de editar, lee `README.md` y `docs/DEVELOPMENT_PLAN.md`. Ejecuta la auditoría de Fase 0 y crea/actualiza `docs/IMPLEMENTATION_STATUS.md`. Implementa las fases en orden, sin declarar funcionalidades terminadas hasta probarlas. Mantén el checkout público y los cobros deshabilitados hasta autorización y bases confirmadas. Nunca inventes datos legales, bancarios ni resultados de pruebas; protege PII y claves. Cada cambio debe incluir pruebas y documentación. Sigue las instrucciones detalladas del plan maestro.
